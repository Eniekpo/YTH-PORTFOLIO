# LinkedIn Project Copy

I built an Executive Business Intelligence & Sales Forecasting Platform to demonstrate how I approach analytics beyond creating charts.

The project takes synthetic transaction data through a complete analytics workflow: data generation, SQL modelling, KPI development, customer segmentation, profitability analysis, forecasting, data-quality checks, and an interactive executive dashboard.

The dashboard helps answer questions such as: Which regions and channels drive revenue? Which product categories create the most gross profit? Which customers are Champions or At Risk? What is the current average order value and gross margin? What could revenue look like over the next several months?

Tech stack: Python, pandas, SQL, SQLite, Streamlit, Plotly, statsmodels, pytest, and Docker.

One part I deliberately included is a Data Quality section. A dashboard can look polished and still mislead decision-makers if the underlying data has not been tested.

All data used in the project is synthetic and generated specifically for portfolio demonstration.
