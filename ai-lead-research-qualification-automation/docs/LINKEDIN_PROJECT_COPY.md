# LinkedIn Project Copy

## Project title
AI-Powered Lead Research, Qualification & Outreach Automation System

## Short description
Built an end-to-end B2B lead-operations automation platform that converts raw prospect records into an explainable qualification queue, evidence-grounded outreach drafts, a mandatory human approval stage, and CRM-ready handoff records.

The system combines Python, FastAPI, Streamlit, SQLite, workflow orchestration, explainable lead scoring, optional LLM-assisted drafting, audit logging, and n8n integration.

A key design decision was keeping a human in the loop: the application does not automatically send outreach. Drafts must be reviewed and approved before handoff.

## Skills demonstrated
Python · FastAPI · Streamlit · REST APIs · SQL · Workflow Automation · AI/LLM Integration · n8n · Data Validation · Lead Scoring · Human-in-the-Loop Automation · Docker · Testing
