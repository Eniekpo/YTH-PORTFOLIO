# Data Dictionary

| Field | Meaning |
|---|---|
| Order_ID | Unique synthetic order identifier |
| Order_Date | Transaction date |
| Region | Sales region |
| City | Sales city |
| Category | Top-level product category |
| Subcategory | Product subcategory |
| Product | Product name |
| Customer_Segment | Consumer, Small Business, or Corporate |
| Channel | Online, Retail Store, or Distributor |
| Salesperson | Synthetic salesperson |
| Quantity | Units sold |
| Unit_Price | Price per unit before discount |
| Unit_Cost | Direct unit cost |
| Discount | Discount rate applied |
| Revenue | Quantity × Unit Price × (1 − Discount) |
| Cost | Quantity × Unit Cost |
| Profit | Revenue − Cost |
| Profit_Margin | Profit ÷ Revenue |
| Year | Calendar year |
| Month | Calendar month name |
| Year_Month | YYYY-MM monthly grouping |
