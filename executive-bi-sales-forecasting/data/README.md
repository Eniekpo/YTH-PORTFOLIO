# Data

All data in this folder is synthetic and generated by `src/data_generator.py` for portfolio demonstration.

- `raw/customers.csv` contains synthetic customer attributes.
- `raw/products.csv` contains synthetic product attributes and unit economics.
- `raw/sales.csv` contains synthetic order-line transactions.
- `processed/executive_bi.sqlite` is the local analytical database created by `setup_project.py`.

No real customer, employer, client, or confidential information is included.
