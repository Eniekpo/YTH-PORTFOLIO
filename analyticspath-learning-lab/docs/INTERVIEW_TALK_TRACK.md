# Interview Talk Track

## 30-second version

I built AnalyticsPath Learning Lab to demonstrate both my analytics capability and my ability to teach technical concepts. Instead of creating isolated Excel, SQL, Python, and Power BI tutorials, I designed one synthetic retail case that moves through every tool. Learners calculate the same KPIs, reconcile results, and finish with an executive capstone.

## What makes it different

- defined learning progression
- exercises before solutions
- same business questions across tools
- cross-tool reconciliation
- knowledge checks
- final capstone and scoring rubric

## Technical choices

- Excel for formulas and first-stage dashboarding
- SQLite for portable SQL practice
- Python/pandas for reproducible analysis
- Power BI/DAX for interactive reporting
- Streamlit for a lightweight learning portal

## Analytical principle

The project trains learners to distinguish association from causation. For example, comparing discount and margin may reveal a pattern, but the learning material warns against claiming the discount caused the result without a stronger analytical design.

## Production extension

I would add user accounts, persistent progress, graded coding exercises, completion certificates, instructor dashboards, hosted SQL sandboxes, notebook autograding, and embedded BI.
