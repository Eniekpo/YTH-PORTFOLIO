# AnalyticsPath Learning Lab
## Interactive Data Analytics Learning Lab: Excel → SQL → Python → Power BI

AnalyticsPath Learning Lab is a portfolio-ready training project that teaches an end-to-end business analytics workflow using one consistent synthetic retail dataset.

Instead of treating Excel, SQL, Python, and Power BI as disconnected tools, the project asks learners to solve the same commercial questions across all four environments and combine the results in a final capstone.

> All data in this repository is synthetic and intended for training and portfolio demonstration.

## What This Project Demonstrates

**Data analytics:** KPI design, data transformation, SQL analysis, Python analysis, visualization, and business interpretation.

**Technical training:** curriculum design, scaffolded exercises, answer keys, assessments, capstone design, and learner-facing documentation.

## Learning Path

```text
Raw Retail Data
      ↓
Excel Fundamentals + KPI Dashboard
      ↓
SQL Querying + Business Questions
      ↓
Python EDA + Visualization
      ↓
Power BI Data Model + DAX
      ↓
Integrated Executive Capstone
```
