## Project
Interactive Data Analytics Learning Lab: Excel → SQL → Python → Power BI

## Description

Built a complete hands-on data analytics learning environment that teaches the same retail business case across Excel, SQL, Python, and Power BI.

The project includes a synthetic 1,800-order dataset, a formula-driven Excel workbook and executive dashboard, a SQLite query lab, starter and solution Python notebooks, a Power BI build guide with DAX measures, assessments, a capstone rubric, and a Streamlit learning portal.

A major design principle was cross-tool reconciliation: learners are expected to produce consistent KPI definitions and results across every environment while distinguishing observed patterns from unsupported causal claims.

**Skills demonstrated:** Excel · SQL · Python · pandas · Power BI · DAX · Data Visualization · Business Analysis · Curriculum Design · Technical Training · Streamlit
