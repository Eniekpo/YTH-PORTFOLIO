# Capstone Rubric

| Area | Weight | Excellent Standard |
|---|---:|---|
| Data accuracy & reconciliation | 20% | KPIs reconcile across tools and calculations are correct. |
| Excel analysis | 15% | Correct formulas, readable dashboard, useful interpretation. |
| SQL analysis | 15% | Correct aggregation, filtering, ranking and time analysis. |
| Python analysis | 20% | Reproducible workflow, quality checks, effective visualizations. |
| Power BI | 20% | Clean model, correct measures, useful interactions and layout. |
| Executive communication | 10% | Findings and recommendations are concise, evidence-based and appropriately qualified. |

## Score Interpretation

- 90–100: Portfolio ready
- 80–89: Strong, minor refinement needed
- 70–79: Competent, several improvements needed
- Below 70: Rework core analytical or communication elements
